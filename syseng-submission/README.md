## 新增 logit/probit 实验与不显著结果的处理（第七轮）

### 1. 新增实验：状态的可预测性（logit 与 probit）

脚本 `src/syseng_logit.py`，输出 `results/logit_probit_summary.csv` 与
`results/logit_probit_detail.json`。设计动机：门控的可实施性取决于状态能否实时识别，
这是本文渠道分解的直接可检验含义。

- 被解释变量：下月状态（二值）——风险结构制度（6 个月波动三分位最高组）、
  收益水平制度（12 个月收益三分位最低组）、制度切换；
- 解释变量：滞后一期的公开信息（上月收益、近 3 个月收益、近 6 个月波动、
  近 1 年回撤、横截面离散度、上涨股票占比），标准化；
- 估计：logit 与 probit 并列，Newey--West（6 阶）标准误，并报告伪 $R^2$、
  样本内命中率与扩展窗样本外命中率。

主要结果（正文表 10）：
制度切换基本不可预测（伪 $R^2$ = 0.041，命中率 0.528，低于「始终预测不切换」的 0.762）；
状态本身判别力强（风险结构制度伪 $R^2$ = 0.449、样本外命中率 0.874；
收益水平制度 0.406、0.754）。平均边际效应显示判别力来源符合渠道分解：
风险结构制度主要由滞后波动率驱动（$+0.194$，$p<0.001$，即波动聚集），
收益水平制度由滞后回撤（$-0.314$）与横截面离散度（$-0.138$）驱动。

经济含义：门控是可实施的（只需月度识别状态，不需预判切换），
但无法通过择时规避切换带来的换手成本——与成本敏感性结果互相印证。

### 2. 关于「去掉不显著结果」的处理

本稿的核心结论本身就是统计不显著的结果（门控相对等权 $+0.115$，Holm $p=0.386$；
互补性统计量未越过噪声底线），删除它会使全文不成立，也违背论文自身的论证立场。
因此本轮按「精简」而非「删除」处理：

- 已删除：年度环境单变量回归中三个不显著系数（$p$ = 0.295 / 0.365 / 0.436）
  的逐项报告，压缩为一句「年度观测只有 12 个，单变量回归不足以支持因果推断」；
- 保留但压缩：训练窗长度的不显著斜率（$p$ = 0.617）——它是比较静态 H4 的反例证据；
- 保留：主结果表的全部 10 个模型（含 4 个区间跨零的模型）——按显著性筛行属于选择性报告；
- 保留：子样本衰减、制度定义敏感性、自助区块长度敏感性、外生冲击分组，
  这些是「边界条件」结论的组成部分。

如确需进一步压缩篇幅，建议的做法是把不显著辅助检验整体移入在线附录，
而不是从主表或结论中删除。
