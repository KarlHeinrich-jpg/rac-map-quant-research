# 多智能体驱动的风险感知自适应量化投资：研究计划

## 研究问题

在公开可复现的跨资产信息集上，五类可解释投资智能体的动作、置信度和风险估计，是否能通过制度状态自适应门控，在严格滚动样本外条件下改善风险调整收益并降低换手？

## 研究对象与模型

主模型暂命名为 Regime-Adaptive Confidence-Weighted Multi-Agent Portfolio（RAC-MAP）。每个智能体输出资产动作、置信度和风险估计，门控器根据市场制度、近期表现、置信度和风险联合计算组合权重。正式版本的智能体应分别对应动量、价值、情绪、波动率和宏观状态；当前公开ETF原型中的趋势/低波动/防御/均值回复是可运行的代理实现，不能在缺乏估值和情绪数据时宣称已经完成“价值智能体”和“情绪智能体”。主目标包含净收益、换手和CVaR惩罚，并与去制度识别、去置信度、去CVaR和静态权重消融比较。

## 数据与信息集

主样本为 2010-03-31 至 2025-12-31 的十只流动性较高 ETF（SPY、QQQ、IWM、EFA、EEM、TLT、GLD、VNQ、LQD、DBC）日频复权行情，并合并 FRED 的 VIX、联邦基金利率、10 年期国债收益率、10Y--2Y 利差和 BAA--10Y 信用利差。宏观观测按公开发布日期至少滞后一个交易日使用；2026 年仅作外部监测，不进入主结论。CRSP/WRDS 需要机构权限，若未提供凭证则不声称已接入。

## 主要基线设计

主结果不以其他多智能体系统作为唯一反事实，而采用三层非智能体基线：

1. 组合规则：buy-and-hold、equal-weight、mean-variance、risk parity、波动率目标组合；
2. 计量模型：历史协方差均值-方差、GARCH(1,1)波动率预测，数据允许时增加DCC-GARCH；
3. 监督学习预测：OLS/forecast combination、Ridge、Lasso、Elastic Net、PLS，以及至少一种SVM、GBDT/XGBoost和MLP/LSTM。所有模型使用相同特征、交易成本和滚动窗口，以预测收益或风险后统一转换为长仓组合。

MASA/FinRL仅作为相关架构的附加兼容性对照或附录，不承担主结果的识别作用。机器学习方法的选择参考附件论文，但不把A股月频多空结果与本研究的ETF日频长仓结果直接比较。

## 样本外设计

每个滚动窗使用过去五年训练、随后一年验证、再后一年测试；每个测试窗独立重置状态并只使用测试开始日前可获得的信息。主测试窗覆盖 2018--2025 年，按年滚动；所有结果按五个随机种子（7、19、42、73、101）重复。报告 CAGR、Sharpe、Sortino、最大回撤、日频 CVaR、换手和交易成本后收益。

## 统计检验

以测试年份为主要市场重复单位，在年份内先汇总多 seed，再对模型差值使用配对 block bootstrap 和 Wilcoxon 检验；同时报告 seed 间优化不确定性。多模型比较采用 Friedman 检验，事后两两比较使用 Holm 校正。统计结果只支持风险调整表现差异，不表述为因果效应。

## 证据边界

当前滚动v3只覆盖规则基线与RAC-MAP，尚未完成上述监督学习和GARCH基线，因此不能把现有结果写成“多智能体优于机器学习或GARCH”。论文主结果必须在非智能体基线实现、同一滚动窗口和多 seed 统计完成后冻结。CRSP/Compustat/SEC点时版本还需解决退市收益、披露日期和估值/情绪变量的可得性。
